Euskotren data is converted from an open source GTFS file.
Some data are lost in the conversion, like the fares or the path.
The original source can be found here https://www.euskadi.eus/moveuskadi-planificador-de-rutas-en-la-red-de-transporte-publico-de-euskadi-horarios-paradas-tiempo-coste-y-otros-datos/web01-ejeduki/es/
The data can be used according to this licence https://creativecommons.org/licenses/by/4.0/

FGC data is converted from an open source GTFS file.
Some data are lost in the converstion, like fares or the path.
The original source can be found here https://www.fgc.cat/google/google_transit.zip

Estonian data is converted from an open source GTFS file.
Only Elron data is converted, bus company data for example is not exported to MERITS.
The original source can be found here http://peatus.ee/gtfs/gtfs.zip

Vivi data  (Latvia) is converted from an open source GTFS file.
Some data are lost in the converstion, like fares or the path.
The original source can be found here https://vivi.lv/uploads/GTFS.zip

EAV data is converted from an open source GTFS file.
Some data are lost in the converstion, like fares or the path.
The original source can be found here https://www.wimob.it/cfile/download.php?file=google-transit.zip

Stena Line data is converted from an open source GTFS file.
Some data are lost in the converstion, like fares or the path.
The original source can be found here https://fgwgtfsprod.blob.core.windows.net/gtfsout/latest_STENA.zip
